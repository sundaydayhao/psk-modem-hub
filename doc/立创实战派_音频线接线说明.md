# 立创实战派音频线接线说明

本文说明立创实战派 ESP32-S3 的音频接口如何接外部设备，重点是 AM 接收机、电台、声卡这类场景。

## 1. 先说结论

- **接收音频输入**走 `ES8311 MIC1P / MIC1N`
- **发射音频输出**走 `ES8311 OUTP / OUTN`
- **喇叭播放**走 `NS4150B` 后面的 `J5` 喇叭接口
- **`PA_IN+ / PA_IN-` 不是对外音频输入口**，它是功放输入

## 2. 一根音频线能不能同时有输入和输出

一般来说，**不能把“输入”和“输出”理解成同一根单芯线同时双向传输**。

常见情况有两种：

1. **普通 3.5mm 线**
   - 通常只负责一个方向，或者只负责一组立体声信号
   - 例如：声卡 Line Out -> 设备输入

2. **TRRS 四段线**
   - 一根物理线里可以同时带左声道、右声道、地和麦克风
   - 但本质上是**多根独立导线**
   - 不是同一根信号线双向共用

所以工程上建议：

- **RX 输入和 TX 输出分开接**
- 如果一定要共用一根线缆，也要用**多芯线**，并且输入/输出必须是不同导线

## 4. 具体怎么接

### 4.1 接收音频输入

把外部音频源接到：

- `MIC1P`
- `MIC1N`

适用来源：

- AM 接收机音频输出
- 电脑声卡 `Line Out`
- 其他低电平音频源

建议：

- 先做衰减
- 再做交流耦合
- 需要时加隔离变压器

### 4.2 发射音频输出

把板子的发射音频从：

- `OUTP`
- `OUTN`

引出后，再接到：

- 电台 `MIC IN`
- 或电台 `LINE IN`

注意：

- 不要直接接 `J5` 喇叭口
- 不要把功放后的扬声器输出当作电台音频输入

### 4.3 本机喇叭

如果只是让板子自己播放声音：

- `OUTP / OUTN -> NS4150B -> J5`

这一路是给扬声器用的，和电台发射音频不是同一条路径。

## 5. 推荐接法

### 5.1 最稳妥

- **RX**：外部音频线 -> `MIC1P/MIC1N`
- **TX**：`OUTP/OUTN` -> 外部音频线 -> 电台输入
- **喇叭**：走 `J5`

### 5.2 不推荐

- 把电台输入直接接 `J5`
- 把外部音频源直接接 `PA_IN+ / PA_IN-`
- 把高电平耳机输出直接硬接到麦克风脚

## 6. 简短结论

如果你说的“一个音频线”是**一根物理线缆**，那它可以做成多芯结构，同时承载输入和输出，但**输入和输出必须是不同导线**。

如果你说的“一个音频线”是**一根信号线**，那通常只能单向。
