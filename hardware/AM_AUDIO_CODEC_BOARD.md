# AM Audio Codec Board Hardware Design

目标：制作一块外接小板，把 AM 接收机音频输出转换为 AIM5101 可采集的数字音频流。小板包含音频输入保护/隔离/衰减、ES8311 codec、I2S/I2C/GPIO 接口。

## 1. 系统框图

```text
AM receiver audio out
        |
        v
3.5mm audio jack / terminal block
        |
        v
isolation + attenuation + protection + AC coupling
        |
        v
ES8311 ADC input
        |
        v
I2S audio stream
        |
        v
AIM5101

AIM5101 I2C ----> ES8311 control registers
AIM5101 GPIO ---> ES8311 reset / power enable / mute
```

说明：这里处理的是 AM 接收机已经解调出来的音频基带，不处理 AM 射频信号。

## 2. 推荐接口

### 2.1 AIM5101 到 ES8311

| AIM5101 pin | Function | ES8311 signal | Direction |
|---|---|---|---|
| `PD9` | `I2S0_MCK` | `MCLK` | AIM5101 -> ES8311 |
| `PC10` | `I2S0_CK` | `SCLK/BCLK` | AIM5101 -> ES8311 |
| `PC9` | `I2S0_WS` | `LRCK/WS` | AIM5101 -> ES8311 |
| `PC11` | `I2S0_SDI0` | `ASDOUT/ADCOUT` | ES8311 -> AIM5101 |
| `PC12` | `I2S0_SDO0` | `DSDIN/DACIN` | AIM5101 -> ES8311, optional |
| `PD10` | `I2C1_SCL` | `SCL` | AIM5101 -> ES8311 |
| `PD11` | `I2C1_SDA` | `SDA` | bidirectional |
| `PA0` | GPIO | codec reset | AIM5101 -> codec board |
| `PA1` | GPIO | codec power enable | AIM5101 -> codec board |
| `PA2` | GPIO | codec mute | AIM5101 -> codec board |

`PC12/I2S0_SDO0` can be left unconnected if the first hardware revision only supports RX.

### 2.2 External Audio Input

Recommended connector:

| Connector pin | Signal |
|---|---|
| Tip | AM audio signal or left channel |
| Ring | optional right channel, mix through resistor |
| Sleeve | audio ground / shield |

For a mono AM receiver, use Tip as signal and Sleeve as ground.

## 3. Audio Input Front End

### 3.1 Basic Line Input

Use this when the source is a PC sound card, phone headphone output, USB audio adapter, or AM receiver headphone/line output.

```text
J1 Tip  -- R1 10k --+
                    +-- R3 2.2k -- AU_GND
J1 Ring -- R2 10k --+
                    |
                    +-- C1 1uF -- R5 100R -- ES8311 MIC1P

J1 Sleeve ---------------------------- AU_GND
ES8311 MIC1N -- C2 1uF --------------- AU_GND
```

Notes:

- `R1/R2` mix stereo to mono and limit current.
- `R3` attenuates line/headphone level before codec input.
- `C1/C2` provide AC coupling.
- `R5` is optional series protection; use `0R` to `1k`, start with `100R`.
- Start with PC output volume at 10%.

### 3.2 Isolated Radio Input

Use this for real radio equipment.

```text
AM audio signal ---- C_in optional ---- T1 600:600 ---- R1 10k --+
                                                                 +-- R3 2.2k -- AU_GND
AM audio ground  ---------------------- T1 600:600 ---- AU_GND --+
                                                                 |
                                                                 +-- C1 1uF -- R5 100R -- MIC1P

MIC1N -- C2 1uF -- AU_GND
```

Recommended additions:

- `T1`: 600:600 audio isolation transformer.
- Add ESD protection near connector.
- Add RF filtering near connector.
- Keep shield/chassis connection separate from sensitive analog ground until the intended single-point connection.

### 3.3 Protection

Add clamp protection after attenuation:

```text
audio_node -- D1 --> AU_3V3 or VMID-safe clamp
audio_node -- D2 --> AU_GND
```

Use small-signal diodes or a low-capacitance ESD device. Avoid clamping directly into a noisy digital 3.3 V rail if it injects noise into the codec input.

## 4. ES8311 Codec

### 4.1 Power

Typical rails, confirm against the ES8311 datasheet and exact package:

| ES8311 pin group | Rail |
|---|---|
| `AVDD` | `AU_3V3` |
| `PVDD` | `AU_3V3` |
| `DVDD` | `AU_3V3` or valid digital core rail per datasheet |
| `DGND` | digital ground |
| `AGND` | audio analog ground |

Decoupling:

- Place `100nF` close to every power pin.
- Add `1uF` to `10uF` bulk capacitor near codec.
- Keep analog decoupling return short to `AU_GND`.

### 4.2 Clocking

Initial target:

```text
sample rate: 8 kHz or 16 kHz
sample width: 16-bit
channel: mono
I2S role: AIM5101 master, ES8311 slave
MCLK: generated by AIM5101 I2S0_MCK if supported
```

If AIM5101 cannot provide a codec-compatible MCLK, add an external oscillator or choose an I2S configuration supported by ES8311 without MCLK only if documented.

### 4.3 I2C

ES8311 address from reference schematic:

```text
I2C address: 0x18
```

Add pull-ups:

```text
SCL -- 4.7k -- 3V3
SDA -- 4.7k -- 3V3
```

Use `2.2k` if the bus is long or capacitance is high.

### 4.4 Control GPIO

Default board control:

| Signal | AIM5101 GPIO | Default active level |
|---|---|---|
| `CODEC_RST_N` | `PA0` | active low |
| `CODEC_PWR_EN` | `PA1` | active high |
| `CODEC_MUTE` | `PA2` | active high |

If the chosen ES8311 circuit does not expose reset/mute/power enable, keep these pins as board-level controls for regulator enable or analog mute.

| 3 | `AU_GND` |
| 4 | `I2S0_MCK` |

| 7 | `I2S0_SDI0` |
| 8 | `I2S0_SDO0` |

Optional:

- Add `INT` from codec if needed.
- Add test points for `MCLK/BCLK/WS/SDOUT/SCL/SDA`.

## 6. PCB Layout Rules

- Put ES8311 close to the audio input conditioning network.
- Put decoupling capacitors next to ES8311 power pins.
- Keep `MIC1P/MIC1N` traces short, symmetric, and away from I2S clocks.
- Route I2S clocks away from analog input.
- Place the 600:600 transformer near the external audio connector.
- Put ESD/RF protection near the connector before long internal traces.
- Use an analog ground area for input and codec analog pins.
- Join analog ground and digital ground at one controlled point near the codec or connector strategy.
- Do not run digital clocks under the codec analog input network.
- Add test pads for:
  - raw audio input after attenuation
  - codec input node before AC coupling
  - `MCLK`
  - `BCLK`
  - `WS`
  - `I2S ADC data`
  - `SCL/SDA`
- Keep I2C pull-ups near the bus or codec side.
- If using a headphone/line source, make input attenuation configurable with resistor footprints.

## 8. Bring-up Checklist

- [ ] Verify no short between `3V3`, `DGND`, and `AU_GND`.
- [ ] Power board and verify codec rails.
- [ ] Verify I2C pull-ups and idle high levels.
- [ ] Run I2C scan and confirm ES8311 at `0x18`.
- [ ] Configure GPIO reset/power/mute.
- [ ] Verify MCLK/BCLK/WS with oscilloscope or logic analyzer.
- [ ] Configure ES8311 ADC and I2S RX.
- [ ] Feed 1 kHz sine at low volume.
- [ ] Confirm I2S samples are nonzero and not clipped.
- [ ] Feed fldigi BPSK31 audio at 1000 Hz or 1500 Hz center.
- [ ] Confirm frequency peak appears at expected audio frequency.
- [ ] Record raw PCM, convert to WAV, and verify PC fldigi can decode it.
- [ ] Connect real AM receiver after PC sound-card path works.
