# pskcoredll121src 目录说明

这个目录是 **PSK31Core / PSKCore 的底层算法与 DLL 工程**。

它的作用是：
- 实现 PSK31/BPSK/QPSK 的收发核心
- 负责音频输入处理、FFT、解调、调制、AFC、波形/窗口处理
- 向上提供 DLL 或静态库接口给 WinPSK 之类的上层程序调用

主要内容：
- `PskDet.cpp`：接收/解调核心
- `PSKMod.cpp`：发送/调制核心
- `fft.cpp`：FFT 实现
- `Sound.cpp` / `Wave.cpp`：声卡和波形文件处理
- `IOCntrl.cpp`：流程控制和线程调度
- `PSKCore.cpp`：DLL 入口和导出接口

和 AIM5101 项目的关系：
- 这是最值得参考的算法层
- 可重点移植接收机状态机、滤波、同步、AFC、调制逻辑
- 需要把声卡/Windows 依赖替换成 I2S、DMA、FreeRTOS 或其他平台接口

一句话总结：
这是 **真正的 PSK 计算核心**，不是界面层。
