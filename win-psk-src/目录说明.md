# winpsksrc213 目录说明

这个目录是 **WinPSK 2.13 的完整 Windows 客户端工程**。

它的作用是：
- 提供 PSK31/QPSK 等数字通信的图形界面
- 负责收发文本、宏、瀑布图、频率调节和用户交互
- 通过 `PSKCore.lib` 调用底层解调/调制核心

主要内容：
- `WinPSK.cpp` / `WinPSKView.cpp` / `MainFrm.cpp`：主程序和界面
- `RcvView.cpp` / `XmitView.cpp`：收发窗口
- `PlotData.cpp`：频谱/瀑布图绘制
- `Settings.cpp`：设置保存
- `PSKCore.lib`：核心库接口

和 AIM5101 项目的关系：
- 更像是“上位机参考”
- 可参考它的 UI 交互、模式切换、收发流程
- 不建议直接照搬为嵌入式实现

一句话总结：
这是 **完整 Windows 前端**，不是核心算法库。
